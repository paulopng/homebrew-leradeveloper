# homebrew-leradeveloper

Tap do Homebrew e bucket do Scoop do [leradeveloper](https://github.com/paulopng/leradeveloper).

**Windows** (Scoop):

```powershell
scoop bucket add leradeveloper https://github.com/paulopng/homebrew-leradeveloper
scoop install leradeveloper
```

**macOS / Linux / WSL** (Homebrew):

```bash
brew install paulopng/leradeveloper/leradeveloper
```

`Formula/leradeveloper.rb` e `bucket/leradeveloper.json` são gerados pelo workflow
de release do repositório principal. Edite os modelos em `packaging/` lá, não aqui.
